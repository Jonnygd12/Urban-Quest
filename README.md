# Urban Quest 1.0.0

Clean React + TypeScript foundation for Urban Quest.

## Included

- Quest HQ and Explorer switching
- Curated Hidden London quest
- Ellis and Erin personalised missions
- GPS distance to the active operation
- Google Maps walking directions
- Discovery Cards and locked secrets
- Mission progression and Quest Points
- Camera/photo compression and local saving
- Quest Memories
- Pit Stop Google Maps search
- Local progress saving
- Mystery clues
- Final printable Case File

## Create the GitHub repository

1. Create a new public repository named `urban-quest`.
2. Upload the complete contents of this package, preserving `.github/workflows/deploy.yml`.
3. Commit to `main`.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **GitHub Actions**.
6. Open the **Actions** tab and wait for `Deploy Urban Quest` to finish.
7. Your app will be available at:

   `https://YOUR_USERNAME.github.io/urban-quest/`

## Local development

```bash
npm install
npm run dev
```
